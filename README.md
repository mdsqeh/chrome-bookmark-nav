# Chrome 本地书签导航

一个本地运行的 Chrome MV3 扩展：将新标签页替换为可搜索、分类卡片式的书签导航页。书签通过 Chrome 的 `chrome.bookmarks` API 在浏览器本地读取，不会上传书签数据。

## 安装步骤（Windows / Chrome）

1. 把仓库克隆或下载到本地一个固定目录，例如 `git clone https://github.com/mdsqeh/chrome-bookmark-nav.git D:\Tools\chrome-bookmark-nav`。不要在安装后移动或删除该目录。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 打开右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `chrome-bookmark-nav` 文件夹。
5. 打开一个新标签页，即可看到导航页。原来的 Chrome 新标签页会被本扩展替换；其他书签功能不受影响。

## 自动同步

扩展会监听书签新增、删除、修改、移动、文件夹排序和导入完成事件。发生变更后会重新读取书签树并刷新页面。已经打开的导航标签页也会响应事件。

## 使用方式

- 默认按“使用频率”排序，使用次数多的书签会排在前面；首页顶部会额外显示最多 8 个已使用过的常用书签。
- 使用次数统计的是“通过这个导航页点击打开”的次数，不会读取或统计你在 Chrome 地址栏、书签栏或其他页面直接访问网站的历史记录。新安装后计数从 0 开始。
- 次数保存在 Chrome 扩展的本地存储中，不会上传。写盘前会先读取最新值再叠加本次增量，因此同时开着多个新标签页也不会互相覆盖。更换 Chrome 配置或移除扩展后，计数可能丢失。
- 可以在右侧排序菜单切换为“名称 A–Z”。选择会被记住，下次打开新标签页仍然生效。
- 输入关键词搜索书签名称、网址或分类（包含所在文件夹的完整层级，例如搜「工作」能命中「工作 / 前端」下的书签）。
- 按回车（Enter）用 Google 搜索当前关键词，结果在新标签页打开；结果列表顶部也会显示「在 Google 中搜索」入口。
- 点击分类按钮，只查看该分类中的书签。
- 点击磁贴，在新标签页打开网站。
- 鼠标在磁贴上停留约 0.6 秒会浮现置顶按钮（已置顶的也一样，出现时为实心高亮），点一下即可置顶或取消；触屏设备上该按钮常显。
- 按 `/` 快速聚焦搜索框，按 `Esc` 清空搜索。
- 点击右上角的刷新按钮可手动重新读取。

## 图标与隐私

网站图标通过 Google Favicon 服务获取。请求里只包含书签的「协议 + 主机」（例如 `https://github.com`），路径、查询参数和锚点都不会发出——带 token 的书签链接不会被泄露。

取到的图标以 dataURL 形式缓存在扩展本地存储（`chrome.storage.local`）中，之后打开新标签页或离线时直接读缓存，不再重复请求；缓存超过 7 天或缺失时才会重新获取。缓存按域名去重，最多 400 条、总量不超过 4MB（超出时按时间淘汰最旧的），不会写满 `storage.local` 的 10MB 配额。图标请求并发上限为 6 个，离线时直接跳过、不发无效请求。

源图小于 64px 时不放大显示，改用「域名配色 + 首字母」方块，避免模糊。书签标题和完整书签列表不会被发送。若希望图标请求完全离线，可在图标缓存建立后断网使用，或改为本地默认图标。

## 故障排查

- 如果新标签页没有变化：确认扩展已启用，并重新打开一个新标签页。
- 如果看到“无法读取 Chrome 书签”：请确认是在 Chrome 中通过 `chrome://extensions/` 加载扩展，而不是直接双击 `newtab.html`。
- 如果扩展目录被移动，Chrome 可能无法加载它；请重新选择新目录加载。
